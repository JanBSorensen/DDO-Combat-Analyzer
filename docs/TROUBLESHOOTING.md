# Troubleshooting

## Combat Log area

Use **Select / adjust log area** before recording.

A dark, opaque Combat Log background gives the most reliable capture and OCR.

## Windows

The Windows version may request Administrator privileges so the global recording hotkey can work while DDO has focus.

Useful log file:

- `_internal/startup_error.log`

## Linux

The current Linux version requires **X11**. Wayland is not supported.

Useful log files:

- `_internal/startup_error.log`
- `_internal/startup_console.log`

## Session files

Session folders contain the recording, analysis output and diagnostic files for that combat session.
