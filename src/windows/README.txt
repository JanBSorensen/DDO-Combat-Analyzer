DDO COMBAT ANALYZER - WINDOWS
==============================

CONTENTS
--------
This folder contains the current Windows source and launch scripts for DDO Combat Analyzer.

START
-----
First-time setup:
  SETUP DDO Combat Analyzer.cmd

Normal start:
  START DDO Combat Analyzer.cmd

MAIN FEATURES
-------------
- Combat Log area selection
- high-frequency recording
- live rolling DPS/APM
- post-combat analysis
- session history and reanalysis
- Replay live test
- per-target combat details

MAIN DEPENDENCIES
-----------------
- Python
- MSS
- OpenCV
- NumPy
- Indra OCR
- FFmpeg

SOURCE
------
Application source is stored in the _internal folder.
